# Architecture decision records

These records describe decisions implemented in the credit-risk ML platform.
They record the current rationale without claiming a historical evaluation or date.
Planned capabilities are tracked in the [roadmap](../../ROADMAP.md).

## Index

- [0001: Package layout](0001-package-layout.md)
- [0002: Python tooling and shared gate](0002-python-tooling.md)
- [0003: Workflow orchestration](0003-workflow-orchestration.md)

## Record template

Use a numbered Markdown file and add it to this index. Each record uses these
sections: Status, Context, Decision, Alternatives, and Consequences. Status states
whether the decision is accepted, proposed, or superseded; alternatives describe
tradeoffs without implying that unrecorded experiments took place.
